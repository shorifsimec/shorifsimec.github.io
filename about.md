## Featured Projects

### 📱 Flutter CI/CD Build & Release

An automated GitHub Actions pipeline for Flutter applications.

The workflow automatically:

- Runs when code is pushed or merged into `main`
- Sets up Java 17 and the stable Flutter SDK
- Installs project dependencies
- Builds a production-ready Android APK
- Publishes the APK as a GitHub Release
- Creates sequential release tags such as `v1`, `v2`, and `v3`

**Tech:** Flutter · Dart · GitHub Actions · Java · Android

[View Repository →](https://github.com/shorifsimec)

### 🧩 JSON Format Validator

A lightweight Node.js utility for safely validating, sanitizing, and formatting JSON strings.

Features include:

- Safe JSON parsing
- Prototype-pollution protection
- Configurable payload-size limits
- Custom indentation and tab formatting
- CommonJS and ES Module support
- Command-line usage
- Express.js integration
- Fail-safe responses without unhandled exceptions

Install it with:

```bash
npm install json-format-validator
```

**Tech:** Node.js · JavaScript · npm · CLI Development

[View Repository →](https://github.com/nishadnyc/json-format-validator)

### 🤖 ServerManagerBot

A Discord bot designed to simplify server setup, organization, and moderation.

Features include:

- Automated server setup from JSON templates
- Custom categories, channels, and roles
- Welcome messages
- Anonymous admin announcements
- Kick, ban, mute, warn, and unban commands
- Warning tracking with automatic moderation actions
- Custom server names and reusable templates

**Tech:** Node.js · JavaScript · Discord API · JSON

[View Repository →](https://github.com/nishadnyc/ServerManagerBot)

### 💬 RapidPro Flutter Plugin

A Flutter plugin created to integrate RapidPro or TextIt messaging channels through Firebase Cloud Messaging.

The plugin supports:

- Firebase channel registration
- Flow initiation
- Message sending
- Workspace and contact configuration
- Push notification handling

This project was developed while contributing to a UNICEF application and involved porting a native RapidPro plugin for Flutter-based mobile applications.

**Tech:** Flutter · Dart · Firebase Cloud Messaging · RapidPro

[View Repository →](https://github.com/nishadnyc/rapid-pro)
